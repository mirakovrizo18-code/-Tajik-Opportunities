# Tajik Opportunities

Добро пожаловать в **Tajik Opportunities** — проект с мощным, красивым и сказочным стилем, который отражает силу, золото и величие.

## 🌟 Особенности проекта

- **Мощный премиальный стиль** (тёмный изумрудный фон, золотые заголовки, красные кнопки)
- **Мерцающие звёзды** на фоне (CSS + JavaScript)
- **Эффект гор** внизу страницы (параллакс)
- **Стеклянные карточки** (Glassmorphism) с золотыми рамками
- **Плавные анимации** (появление, свечение, пульсация)

## 📂 Структура файлов

| Файл | Папка | Описание |
|------|-------|----------|
| `index.html` | Корень | Главная страница |
| `404.html` | Корень | Страница ошибки |
| `css/main.css` | `css/` | Все стили |
| `js/script.js` | `js/` | Скрипты для эффектов |

## 🚀 Как запустить

1. Создай репозиторий на GitHub.
2. Загрузи все файлы (структуру выше).
3. Включи **GitHub Pages** (Settings -> Pages -> Source: main branch).
4. Твой сайт автоматически откроется!
